Methodology & Limitations

← Back to dashboard

What this site does

Senate Stock Watch flags a senator's disclosed stock purchase when it falls within an industry that a committee they currently sit on has jurisdiction over. It exists to surface topical correlations worth a closer look, not to accuse anyone of wrongdoing.

Where the data comes from

Every trade shown here is scraped directly from efdsearch.senate.gov, the Senate's own official financial disclosure system, where senators file Periodic Transaction Reports (PTRs) as required by the STOCK Act. Committee assignments come from the unitedstates/congress-legislators open civic-data project. Each ticker's industry classification comes from SEC EDGAR's SIC code for the issuing company. Nothing here comes from a third-party paid data vendor.

How a "flag" is generated

A trade is flagged when all of the following are true:

  • It's a Purchase (sales are shown in the All Trades view but never flagged).
  • Its ticker was successfully classified with an SIC industry code by SEC EDGAR.
  • It was disclosed within the last 45 days - the same window the STOCK Act itself requires senators to disclose within, so this reflects the most recently public information.
  • The trading senator currently sits on a committee whose curated industry mapping matches that ticker's SIC code (or, as a fallback, a keyword in the asset's name).

The committee→industry mapping is a judgment call

There is no free, authoritative dataset that says "Committee X has jurisdiction over industry Y." That mapping is hand-curated and maintained in config/committee_industry_map.yaml in this project's GitHub repository, versioned like code and open to review by anyone. Each mapping carries a confidence level (shown on every flag) reflecting how cleanly that committee's real legislative jurisdiction maps onto a specific set of industries. Committees whose jurisdiction is procedural or spans virtually every industry (Appropriations, Budget, Judiciary, Rules, Small Business, and a few others) are deliberately excluded from matching entirely, since forcing an industry mapping onto them would mostly produce noise.

Other limitations worth knowing

  • Amounts are ranges, not exact figures. The STOCK Act only requires disclosure of a dollar range (e.g. "$1,001 - $15,000"), never the precise trade size.
  • Disclosure can lag the actual trade by up to 45 days. The dashboard's recency is relative to disclosure date, not the date the trade actually happened.
  • Some filings are scanned/handwritten rather than structured and can't be reliably auto-parsed. These show up as "unparsed" rather than being silently dropped.
  • Not every ticker can be classified. Bonds, options, mutual funds, and some foreign issuers aren't in SEC's ticker map and are shown as "unclassified" rather than hidden.
  • This project currently covers the Senate only. House disclosures are largely scanned/handwritten PDFs that can't be reliably parsed yet, so House data is not included.

Data freshness

Trade data refreshes automatically on a schedule (see the "Trades checked" timestamp on the dashboard). The senator/committee roster refreshes separately and less often, since it only changes when a new Congress is sworn in or committee assignments shift (see "Roster last verified").
